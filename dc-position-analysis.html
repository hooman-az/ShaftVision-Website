DC Position Analysis from Proximity Probe Signals

The DC component of an eddy-current proximity-probe output represents the average gap between the probe tip and the shaft target. With correctly oriented X-Y probes, a known reference and bearing geometry, these readings can be used to assess average radial shaft position.

DC and AC are not interchangeable

DC gap/position data describes the mean shaft location relative to the probe mounting reference. The AC component describes dynamic shaft motion and is used for vibration and orbit analysis. ShaftVision analyses the DC Position domain only; AC waveform, orbit and full-spectrum analysis are outside its software scope.

Why reference readings matter

A voltage value alone does not define the rotor's position inside a bearing. The engineer needs the probe sensitivity and orientation, the confirmed rest/reference readings, the operating readings and the bearing-clearance geometry. Without a valid reference and coordinate convention, a calculated position can be misleading.

Typical inputs for a DC Position assessment

  • X and Y DC readings at the reference/rest condition.
  • X and Y DC readings at the operating condition.
  • Probe sensitivity and installed angular orientation.
  • Bearing clearance and the relevant mechanical reference geometry.

How reference-based displacement is calculated

The assessment starts with the difference between each operating DC reading and its corresponding confirmed rest/reference reading. The voltage difference is converted to displacement using the applicable probe sensitivity, then interpreted using the installed probe angle and calibration polarity. The X and Y channel contributions are combined in the agreed machine coordinate system to establish the relative shaft-position change.

Engineering principle

Reference-to-running change = (running DC reading − reference DC reading) ÷ probe sensitivity, with the installed calibration polarity and probe orientation applied. The reference position is retained as the baseline; it must not be replaced by an assumed bearing-centre coordinate.

Probe angles, sensitivity units, polarity and the reference condition must be checked before interpreting the calculated position. A numerically plausible result can still be wrong if the probe orientation or sign convention is entered incorrectly.

Common questions about DC Position

Does a DC gap reading show vibration?

No. The DC component represents the average probe-to-shaft gap. Dynamic vibration is represented by the AC component and requires a different analysis workflow.

Why are rest/reference readings required?

They establish the measured baseline for the installed probes. Operating readings are compared with that baseline so the calculated movement is tied to the actual reference condition rather than an assumed zero position.

Can the result be compared with bearing clearance?

Yes, when the bearing-clearance geometry and coordinate reference are known. The appropriate circular or elliptical clearance boundary should reflect the bearing geometry entered for the assessment.
