Average Shaft Centerline Analysis

Average Shaft Centerline Analysis describes the rotor’s mean radial position within a fluid-film journal bearing. This technical guide explains how X-Y eddy-current proximity-probe DC readings, the confirmed mechanical rest reference, installed probe angles and bearing-clearance geometry are used to assess shaft position. Explore ShaftVision software for reference-based DC Position analysis.

Important measurement distinction

The average shaft centerline is derived from the DC component of proximity-probe signals. AC dynamic vibration and orbit analysis use different signal information. ShaftVision Core Fault Diagnostics evaluates DC Position; it is not an orbit analyzer and does not process AC waveform or full-spectrum files.

What does a shaft centerline plot tell an engineer?

In a fluid-film journal bearing, the rotor does not normally operate exactly at the geometric centre of the bearing. Its average position is influenced by the machine's operating condition, bearing geometry, load and rotor-system characteristics. A shaft centerline view helps an engineer understand the radial location of that average position relative to a defined reference and the available bearing clearance.

What data is needed?

  • X and Y proximity-probe DC gap readings for the relevant measurement condition.
  • A confirmed reference or rest position, with the reference readings recorded consistently.
  • Probe orientation/angles and the applicable probe sensitivity.
  • Bearing-clearance information and the geometry needed to interpret radial position.

How ShaftVision approaches DC position

ShaftVision provides a structured workflow for recording the reference condition, entering operating DC readings, calculating average shaft-centerline position from the probe geometry, and reviewing the result in relation to bearing clearance. The purpose is to make the position assessment clear and traceable—not to substitute dynamic vibration analysis or a complete machinery diagnostic investigation.

Practical workflow for average shaft centerline analysis

  1. Confirm the reference. Record the actual X and Y DC readings at the defined mechanical rest condition; do not substitute an assumed bearing-centre position.
  2. Verify probe configuration. Check each probe’s installed angle, calibration polarity and applicable sensitivity before converting voltage changes to displacement.
  3. Enter operating readings. Compare running DC readings with the corresponding reference readings using the same channel definitions.
  4. Apply bearing geometry. Interpret the calculated radial position using the entered clearance dimensions and the appropriate circular or elliptical model.
  5. Review within scope. Treat the result as a DC average-position assessment; use AC vibration, spectra, waveforms and process evidence separately when investigating dynamic faults.

Reading shaft position against bearing clearance

The calculated average shaft position should be interpreted from the entered mechanical reference and the actual bearing-clearance geometry. The bearing centre is not automatically the measurement origin, and the rest/reference position should remain visible as the baseline for the assessment.

Clearance shape matters. A circular clearance model and an elliptical clearance model are different geometric assumptions; the model selected for an assessment should match the bearing information available. The radial position and its relationship to the applicable clearance boundary should be reviewed together, rather than relying on a single probe voltage or an unreferenced displacement value.

Questions engineers commonly ask

Is shaft centerline analysis the same as an orbit plot?

No. Average shaft centerline analysis uses the DC component of proximity-probe signals to assess mean shaft position. An orbit plot represents dynamic shaft motion using AC vibration information.

Does the rest position have to be at the bearing centre?

No. The recorded mechanical rest/reference condition is the baseline. It should not be silently replaced with the bearing centre or another assumed coordinate.

Why does bearing-clearance geometry matter?

The clearance boundary provides the geometric context for interpreting the calculated shaft position. The selected circular or elliptical representation should reflect the actual bearing data used in the assessment.
